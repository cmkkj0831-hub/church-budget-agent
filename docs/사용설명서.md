# 초등부 교사회 예산 관리 앱 사용설명서

이 앱은 회계담당 한 사람이 1년 동안 **예산신청서·집행보고서를 만들고, 회계 장부를 관리**하도록 돕습니다.
개발자 없이 이 앱만으로 한 해를 시작하고 마칠 수 있게 만들었습니다.

> 꼭 기억할 세 가지
> 1. 장부에 들어가기 전에는 항상 **미리보기와 확인 체크**가 나옵니다. 숫자를 한 번 더 보고 누르세요.
> 2. 잘못 반영했다면 **오류 관리 › 이력**에서 그 반영을 통째로 **되돌릴** 수 있습니다.
> 3. 금액·누계·문서번호는 앱이 계산합니다. Claude(AI)는 영수증 읽기와 문장 쓰기만 돕습니다.

---

## 0. 로그인
- 회계담당(관리자) 비밀번호로 로그인하면 모든 화면이 보입니다.
- 처음 쓸 때는 개발자가 알려 준 **최초 비밀번호**로 들어간 뒤, **설정 › 관리자**에서 내 비밀번호로 바꾸세요.
- 열람용 비밀번호가 있다면, 그 비밀번호로는 **대시보드 보기와 엑셀 내려받기**만 됩니다.
- 화면 위에는 **현재 회계연도**와 **미해결 이슈** 개수가 색으로 보입니다.
  빨강 = 문서 오류, 주황 = 예산 경고(계획보다 많이 씀), 회색 = 증빙 누락·확인 필요.

## 1. 📝 예산 신청서
1. "어떤 행사인가요?"에 짧게 적습니다. 예: `12월 20일 성탄 행사, 어린이 120명, 간식 3000원씩, 선물 5000원씩`
2. **초안 만들기**를 누르면 칸이 채워집니다. 비어 있는 정보는 파란 상자로 물어봅니다.
3. 세부내역 표에서 단가·수량을 고치면 합계·누계·잔여가 바로 다시 계산됩니다.
4. **검증 결과**: 빨간 오류가 있으면 만들 수 없습니다. 노란 경고는 확인 체크 후 진행할 수 있고, 진행하면 이슈로 자동 등록됩니다.
5. 예금주가 다른 문서라면 **이 문서만 다른 계좌 쓰기**를 펼쳐 입력합니다(그 문서에만 들어감).
6. 미리보기를 확인하고 **신청서 생성·장부 반영** → hwpx를 내려받아 안내된 폴더(예: `2026/12월`)에 저장합니다.

## 2. 🧾 집행 보고서
1. 보고서가 아직 없는 신청서를 고릅니다.
2. 영수증 사진·PDF를 여러 장 올리고, **경과보고(자연어)**에 무엇을 언제 누구와 썼는지 적습니다.
   예: `8/15 미사 후 식대 29만2천원 연재, 플로라`
3. **영수증 읽기** → 표에서 날짜·상호·금액을 고칠 수 있습니다.
   - "대행사 ⚠️" 표시: 카드전표에 결제대행사 이름(나이스정보통신 등)이 찍힌 경우입니다. **실제 상호** 칸에 가게 이름을 적으세요.
4. **보고서 초안 만들기** → 경과보고 문장과 세부내역이 만들어집니다. 문장은 직접 고칠 수 있습니다.
   - 세례명이 같은 교사가 두 명이면 누구인지 고르는 칸이 나옵니다.
5. 노란 상자(🔎)는 영수증과 경과보고가 맞지 않는 곳입니다. 확인 후 **보고서 생성** → 보고서 hwpx와 영수증 첨부 docx가 zip으로 내려받아집니다.
   - 신청액보다 적게 쓰면 남은 돈은 **반납(잔액)**, 더 쓰면 넘는 금액은 **자체예산**으로 자동 계산됩니다.

## 3. 🔁 사후 정산
신청서 없이 먼저 쓴 비용을 정리할 때 씁니다.
1. 사업을 고르고 영수증과 경과보고를 넣습니다.
2. **한도 계산** 표: 사업 계획에서 남은 금액(한도)까지만 신청하고, 넘는 금액은 자체예산이 됩니다.
3. 신청서(N번)와 보고서(N+1번)가 같은 날짜로 한 번에 만들어집니다.

## 4. ⚠️ 오류 관리
장부의 틀린 곳·확인할 곳(이슈)을 정리합니다.
- **이슈 목록**: 상태·유형·월로 거를 수 있고, 예산에 미치는 금액이 보입니다.
- 이슈를 고르면 **쉬운 설명**과 **장부 값 vs 계산값**이 나옵니다.
- 아래 칸에 무슨 일이 있었는지 적고(필요하면 원본 hwpx도 올리고) **분석**을 누르면 처리안이 나옵니다.
  - 정정: 장부 값을 고침 / 설명: 값은 두고 이유만 남김 / 추가 확인 필요: 무엇을 더 알려 줘야 하는지 질문
- 처리안의 **변경 전후 표**와 **함께 해결할 이슈**를 확인하고, 확인 체크 후 **반영**합니다.
- 아직 확인 중이면 **메모만 저장하고 '확인중'으로 표시**할 수 있습니다.
- **이력** 탭: 반영 하나하나가 기록됩니다. 잘못 반영했다면 골라서 **되돌리기**(장부·이슈가 함께 반영 전으로 돌아가고, 되돌린 것도 기록됨).
  그 뒤에 같은 칸이 다시 바뀌었다면 되돌릴 수 없다고 알려 줍니다.
- **장부 재검사**: 장부 전체를 다시 검사해 새 이슈 후보를 보여 줍니다. 등록할 것만 체크해서 등록합니다.

## 5. 📊 대시보드
- 위에서 **회계연도**를 고릅니다. 지난 연도는 읽기 전용입니다.
- **회계 현황**: 배정액, 신청 누계, 잔여, 집행률, 자체예산 합.
  - 누계는 "문서에 적힌 값"과 "다시 계산한 값"을 함께 보여 줍니다. 둘이 다르면 어떤 이슈 때문인지 연결해 보여 줍니다.
  - 장부 표: 검색, 신청서/보고서만 보기, 이슈 있는 문서만 보기. 비고 색은 이슈 종류입니다.
  - **회계내역 xlsx** 내려받기(이슈·누계 시트 포함).
- **사업계획서**: 사업별 계획 대비 집행액·집행률·연말 예상. 주황 줄은 연말에 계획을 넘을 것으로 보이는 사업입니다.
- **사용량**(회계담당만): Claude 사용 횟수·토큰·예상 비용. 내년 예산 신청 근거로 CSV를 내려받을 수 있습니다.
  예상 비용을 보려면 설정에서 토큰 단가와 환율을 먼저 입력하세요.

## 6. ⚙️ 설정
- **기본 정보·연락처**: 본당명·분과·기안자·교사명단. 연락처·계좌는 가려져 있고 **보기**를 켜야 보입니다(암호화 저장).
- **금액·문서 양식**: 배정액, 운영비 단가·교사 수, 문서번호 앞부분, 다음 번호, 기본 시각, 결재란.
- **Claude 모델·사용량 단가**: 모델 이름, 토큰 단가(USD/100만 토큰), 환율.
- **관리자**: 비밀번호 변경(현재 비밀번호 확인), Claude API 키 상태(설정됨/없음, 끝 4자리, 마지막 성공 호출).
  - API 키는 앱에서 넣지 않습니다. **키 교체는 개발자에게 안전하게 전달**하세요.

## 7. 🗓️ 회계연도 전환 (1년에 한 번)
한 단계씩 진행하며, 중간에 나갔다 와도 이어서 할 수 있습니다. 새 장부를 만들기 전까지는 **전환 취소**도 됩니다.
1. **지난해 마감**: 연간 결산 엑셀을 내려받아 보관 → 지난해를 읽기 전용으로 바꿈.
2. **미해결 이슈 이월**: 새해로 넘길 이슈를 골라 체크.
3. **새 사업계획서**: 작년과 같은 형식의 엑셀을 올리거나, 사업계획서 사진을 올리거나(Claude가 읽음), 작년 계획을 복사해 고칩니다.
   표에서 고친 뒤 합계·월별 배분 검증이 통과하면 확정.
4. **배정액 확정 → 새 장부 생성**: 문서번호 001부터, 누계 0으로 시작합니다.
5. **기본 정보·기안자·연락처·계좌·교사명단** 갱신.
6. **관리자 비밀번호** 변경, API 키 상태 확인.

## 8. 📋 인수인계 (담당자가 바뀔 때)
- **체크리스트**: 비밀번호 변경, API 키 교체 요청, 계좌 확인, 미해결 이슈 검토, 사용설명서 읽기.
- **인수인계 패키지**: 장부·이슈·이력·사업계획서 엑셀과 설정(민감값 제외), 이 설명서를 zip 하나로 내려받습니다.

## 자주 묻는 것
- **저장이 안 되고 "다른 곳에서 먼저 수정됨"이 나와요** → 왼쪽 **새로 불러오기**를 누르고 다시 하세요(두 화면에서 동시에 고친 경우).
- **비밀번호를 잊었어요** → 개발자가 알고 있는 최초(비상) 비밀번호로 들어가 새 비밀번호를 정하세요.
- **Claude가 틀리게 읽었어요** → 표와 문장은 모두 고칠 수 있습니다. 금액은 영수증 표의 값으로 다시 계산됩니다.
