# 초등부 교사회 집행보고서 앱 사용설명서

이 앱은 **영수증 사진으로 예산집행보고서(서식2) hwpx와 영수증 첨부 docx를 만들어 줍니다.**
화면은 🧾 **집행 보고서**와 ⚙️ **설정** 두 개뿐입니다. 장부는 따로 관리하지 않습니다.

> 꼭 기억할 것
> - **행사·목적**을 적고 영수증 이미지를 올리면 됩니다. 앱이 그 맥락에 맞춰 **경과보고**와 **합계(B)**를 채우고, 설정에 넣어 둔 값(주관단체·기안자·연락처·계좌 등)을 넣습니다.
> - 행사·목적은 행사명·목적 칸에 그대로 들어갑니다. 나머지 칸(문서번호·작성일·일시·인원·세부내역·본당보조·잔액 등)은 **빈칸**으로 나옵니다. 한글에서 직접 채우세요.
> - 합계는 앱이 영수증 금액을 더해 계산합니다. Claude(AI)는 영수증 읽기와 경과보고 문장만 씁니다.

---

## 처음 맡은 날
1. **접속**: 앱 주소를 휴대폰·PC 즐겨찾기에 넣습니다. 앱은 **초대받은 이메일**로만 열립니다(앱 안에 비밀번호는 없음).
   한동안 아무도 안 썼다면 "앱이 잠들었다"는 화면이 나옵니다. 깨우기 버튼을 누르고 1분쯤 기다리세요.
2. **설정 확인**: ⚙️ 설정 › 기본 정보·연락처에서 회계연도, 기안자, 연락처, 은행명·계좌번호·예금주, 교사명단을 확인하고 저장합니다.
   여기 값이 보고서에 자동으로 들어갑니다.
3. **이전 담당자 제거 요청**: 개발자에게 앱 공유 설정에서 새 담당자를 초대하고 이전 담당자를 빼 달라고 합니다.

## 🧾 집행 보고서
1. **행사**와 **목적**을 자연스럽게 적습니다(선택이지만 적으면 경과보고가 더 정확해집니다).
   예: 행사 `10월 초등부 교리 후 간식`, 목적 `교리에 참여한 어린이 격려`
   → 경과보고 `10월 초등부 교리 간식비를 다음과 같이 사용하였습니다. / 10월 20일 교리 후 어린이 간식 구입 : 55,000원`
   적은 행사·목적은 양식의 **행사명·목적 칸에 그대로** 들어가고, 경과보고를 쓰는 맥락으로도 쓰입니다.
2. 영수증 사진·PDF를 여러 장 올립니다.
3. **보고서 만들기**를 누르면 Claude가 영수증을 읽고 경과보고를 씁니다(영수증 수에 따라 수십 초).
4. 화면에 경과보고, 합계, 읽은 영수증 표가 보입니다. 🔎 노란 상자는 확인이 필요한 영수증입니다(금액·날짜를 못 읽음, 결제대행사 이름 등).
5. **zip 내려받기** → 풀면 보고서 hwpx와 영수증 첨부 docx가 있습니다. 파일 이름은 `집행보고서_가장이른영수증날짜`입니다.
6. hwpx를 한글로 열어 빈칸(문서번호·작성일·일시·인원·세부내역·본당보조·잔액 등)을 채우고, 경과보고·합계도 확인·수정합니다.

## ⚙️ 설정
- **기본 정보·연락처**: 본당명·분과·회계연도·기안자·기본 장소·참가대상, 연락처·계좌, 교사명단.
  주관단체·기안자·기안단체장·기본 장소·참가대상·연락처·계좌가 보고서에 들어갑니다. 넣고 싶지 않은 칸은 비워 두세요.
- **Claude 모델·API 키**: 모델 이름, API 키 상태(설정됨/없음, 끝 4자리). API 키는 앱에서 넣지 않습니다. **키 교체는 개발자에게 안전하게 전달**하세요.
- 새 회계연도가 되면 **회계연도**만 바꾸면 됩니다(영수증 날짜 해석에 씁니다).

## 자주 하는 실수와 대처
- **경과보고나 합계가 틀렸어요** → 한글에서 직접 고치거나, 영수증을 다시 찍어 **다른 보고서 만들기**로 새로 만드세요(앱에는 저장되지 않음).
- **문서에 계좌·연락처가 비어 있어요** → ⚙️ 설정 › 기본 정보·연락처에 값이 있는지 확인하세요. 비어 있으면 문서도 빈칸입니다.
- **휴대폰으로 영수증을 찍었는데 안 올라가요** → 한 장에 30MB까지입니다. 일반 화질로 다시 찍거나 화면 캡처를 올리세요.
- **Claude가 금액을 못 읽었어요** → 🔎 경고에 나온 영수증은 합계에 0원으로 들어갑니다. 한글에서 합계를 고치거나 더 선명하게 찍어 다시 만드세요.
- **앱이 안 열리고 "접근 권한이 없다"고 나와요** → 초대받은 이메일로 로그인했는지 확인하고, 아니면 개발자에게 초대를 요청하세요.
- **"다른 곳에서 먼저 수정됨"이 나와요** → 왼쪽 **새로 불러오기**를 누르고 다시 저장하세요(두 화면에서 설정을 동시에 고친 경우).
