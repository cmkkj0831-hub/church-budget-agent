# 초등부 교사회 집행보고서 앱 사용설명서

이 앱은 **영수증 사진으로 예산집행보고서(서식2) hwpx와 영수증 첨부 docx를 만들어 줍니다.**
화면은 🧾 **집행 보고서**와 ⚙️ **설정** 두 개뿐입니다. 장부는 따로 관리하지 않습니다.

> 꼭 기억할 두 가지
> 1. 금액(본당보조·자체예산·잔액)은 앱이 계산합니다. Claude(AI)는 영수증 읽기와 경과보고 문장만 돕습니다.
> 2. 문서번호·연결 신청서 번호·신청액은 직접 적습니다. 앱이 번호를 이어서 매기지 않습니다.

---

## 처음 맡은 날
1. **접속**: 앱 주소를 휴대폰·PC 즐겨찾기에 넣습니다. 앱은 **초대받은 이메일**로만 열립니다(앱 안에 비밀번호는 없음).
   한동안 아무도 안 썼다면 "앱이 잠들었다"는 화면이 나옵니다. 깨우기 버튼을 누르고 1분쯤 기다리세요.
2. **설정 확인**: ⚙️ 설정 › 기본 정보·연락처에서 회계연도, 기안자, 연락처, 은행명·계좌번호·예금주, 교사명단을 확인하고 저장합니다.
   여기 값이 보고서에 자동으로 들어갑니다.
3. **이전 담당자 제거 요청**: 개발자에게 앱 공유 설정에서 새 담당자를 초대하고 이전 담당자를 빼 달라고 합니다.

## 🧾 집행 보고서
1. **문서 정보**를 적습니다.
   - 행사명, 대상 월(저장 폴더 기준), 목적(선택)
   - 보고서 문서번호(앞부분 `(집)2026-`이 미리 들어가 있음), 연결 신청서 문서번호
   - **신청액**: 연결 신청서의 금번신청액. 이 값으로 본당보조·자체예산·잔액이 계산됩니다.
2. 영수증 사진·PDF를 여러 장 올리고, 필요하면 **경과보고(자연어)**에 무엇을 언제 누구와 썼는지 적습니다.
   예: `8/15 미사 후 식대 29만2천원 연재, 플로라`
3. **행사 정보**(일시·장소·참가대상·인원)를 채웁니다.
   - 날짜를 비워 두면 영수증을 읽은 뒤 영수증 날짜(가장 이른 날~가장 늦은 날)로 채워집니다.
   - 장소·참가대상을 비우면 설정 기본값, 시각을 비우면 설정 기본 시각이 들어갑니다.
4. **영수증 읽기** → 표에서 날짜·상호·금액을 고칠 수 있습니다.
   - "대행사 ⚠️": 카드전표에 결제대행사 이름(나이스정보통신 등)이 찍힌 경우입니다. **실제 상호** 칸에 가게 이름을 적으세요.
5. **보고서 초안 만들기** → 경과보고 문장과 세부내역이 만들어집니다. 문장은 직접 고칠 수 있습니다.
   - 세례명이 같은 교사가 두 명이면 누구인지 고르는 칸이 나옵니다.
   - 🔎 노란 상자는 영수증과 경과보고가 맞지 않는 곳입니다.
6. **금액·검증**에서 본당보조·자체예산·잔액을 확인합니다.
   - 신청액보다 적게 쓰면 남은 돈은 **잔액(반납)**, 더 쓰면 넘는 금액은 **자체예산**입니다.
   - 예금주가 다른 문서라면 **이 문서만 다른 계좌 쓰기**를 펼쳐 입력합니다(그 문서에만 들어가고 설정은 그대로).
7. **보고서 만들기** → 보고서 hwpx와 영수증 첨부 docx가 zip으로 내려받아집니다.
   안내된 폴더(예: `2026/10월`)에 풀어서 저장하세요.

## ⚙️ 설정
- **기본 정보·연락처**: 본당명·분과·회계연도·기안자·기본 장소·참가대상, 연락처·계좌, 교사명단.
- **문서 양식**: 보고서 번호 앞부분(`{연도}`는 회계연도로 바뀜), 기본 시작·종료 시각, 세부내역이 7행을 넘을 때 처리(행 복제 / 묶기).
- **Claude 모델·API 키**: 모델 이름, API 키 상태(설정됨/없음, 끝 4자리). API 키는 앱에서 넣지 않습니다. **키 교체는 개발자에게 안전하게 전달**하세요.
- 새 회계연도가 되면 **회계연도**만 바꾸면 됩니다.

## 자주 하는 실수와 대처
- **금액이나 내용을 잘못 넣고 만들었어요** → 앱에는 저장되지 않으니, 고쳐서 다시 **보고서 만들기**를 누르고 새 파일을 쓰세요.
- **문서에 계좌·연락처가 비어 있어요** → ⚙️ 설정 › 기본 정보·연락처에 값이 있는지 확인하세요. 비어 있으면 문서도 빈칸입니다.
- **휴대폰으로 영수증을 찍었는데 안 올라가요** → 한 장에 30MB까지입니다. 일반 화질로 다시 찍거나 화면 캡처를 올리세요.
- **Claude가 틀리게 읽었어요** → 영수증 표와 경과보고는 모두 고칠 수 있습니다. 금액은 영수증 표의 값으로 다시 계산됩니다.
- **앱이 안 열리고 "접근 권한이 없다"고 나와요** → 초대받은 이메일로 로그인했는지 확인하고, 아니면 개발자에게 초대를 요청하세요.
- **"다른 곳에서 먼저 수정됨"이 나와요** → 왼쪽 **새로 불러오기**를 누르고 다시 저장하세요(두 화면에서 설정을 동시에 고친 경우).
