# 초등부 교사회 예산 앱 접속 안내 (회계담당용)

**앱 주소**: `https://<배포 후 기록>.streamlit.app`
(휴대폰·PC 브라우저 즐겨찾기에 넣어 두세요. 오래 안 쓰면 "잠들었다"는 화면이 나옵니다 → 깨우기 버튼을 누르고 1분 기다리기)

## 로그인
- 비밀번호 칸에 **회계담당 비밀번호**를 넣고 [로그인].
- 처음에는 개발자에게 받은 **최초 비밀번호**로 들어갑니다. 들어가면 설정 화면이 먼저 열립니다.
- 비밀번호를 잊으면 개발자에게 연락하세요(비상 복구용 비밀번호로 들어가 새로 정합니다).

## 처음 할 일 3가지
1. **비밀번호 바꾸기** — 설정 › 관리자 탭 › 현재 비밀번호와 새 비밀번호(8자 이상) 입력.
2. **계좌·연락처 확인** — 설정 › 기본 정보·연락처 › [연락처·계좌 보기]를 켜고 확인·수정 후 저장.
3. **인수인계 체크리스트** — 왼쪽 메뉴 📋 인수인계에서 항목을 하나씩 체크.

자세한 사용법은 앱의 📋 인수인계 › **사용설명서** 탭에 있습니다.
